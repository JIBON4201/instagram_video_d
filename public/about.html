About Reel Downloader

What It Is

Reel Downloader is a self-hosted Instagram reel downloader with a web UI and command-line interface. It lets you paste an Instagram reel link, pick a quality, and save a clean MP4 — no login, no watermark, no ads.

How It Works

The server uses yt-dlp to extract metadata and streams from Instagram, and FFmpeg to merge and convert video to universally playable H.264 MP4. Downloads are processed on the server where the tool is hosted and streamed to your browser.

Quality Modes

  • Best: Highest quality, converted to H.264/AAC for maximum compatibility
  • Original: Source stream remuxed without re-encoding (fastest)
  • Data saver: Progressive MP4, smallest file size

Tech Stack

  • Node.js (stdlib only, no npm runtime dependencies)
  • yt-dlp (media extraction)
  • FFmpeg (merge / transcode / probe)
  • Vanilla HTML/CSS/JavaScript (no build step)
